# Algorithms practice

Algorithms and data structures implemented in Python, following CLRS (*Introduction to Algorithms*) chapter order.

Each file includes:
- The algorithm implemented cleanly
- Big-O time and space complexity in the docstring
- A hand-traced example in comments
- A small test at the bottom

LeetCode solutions are in `leetcode/` — named by problem number, with the approach explained in a comment at the top.
